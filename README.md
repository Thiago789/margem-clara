# Margem Clara

Demonstracao publica e estatica do Margem Clara, um sistema em desenvolvimento para gestao de margem consignavel.

## Demonstracao

Acesse: https://thiago789.github.io/margem-clara/

Os dados exibidos sao inteiramente ficticios. Esta demonstracao nao possui conexao com banco de dados, nao processa dados reais e nao representa um ambiente de producao.

O sistema operacional, suas regras internas e sua infraestrutura sao mantidos em repositorio privado.
